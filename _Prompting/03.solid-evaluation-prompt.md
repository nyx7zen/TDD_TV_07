## 개선 코드 예시

핵심은 `TVChannelController`를 “버튼 이벤트 조율자”로 낮추고, 입력 버퍼와 선호 채널 정책을 분리하는 것입니다.

```cpp
class ChannelInputBuffer {
    int value_ = -1;

public:
    void pressDigit(int digit) {
        if (digit < 0 || digit > 9) {
            throw std::invalid_argument("invalid digit");
        }

        value_ = (value_ < 0) ? digit : value_ * 10 + digit;
    }

    bool hasValue() const {
        return value_ >= 0;
    }

    int consume() {
        int value = value_;
        value_ = -1;
        return value;
    }

    void clear() {
        value_ = -1;
    }
};
```

```cpp
class FavoriteChannels {
    std::vector<int> channels_;

public:
    void toggle(int channel) {
        auto it = std::find(channels_.begin(), channels_.end(), channel);
        if (it == channels_.end()) {
            channels_.push_back(channel);
            std::sort(channels_.begin(), channels_.end());
        } else {
            channels_.erase(it);
        }
    }

    bool empty() const {
        return channels_.empty();
    }

    int nextAfter(int current) const {
        auto it = std::upper_bound(channels_.begin(), channels_.end(), current);
        return it != channels_.end() ? *it : channels_.front();
    }

    const std::vector<int>& values() const {
        return channels_;
    }
};
```

`ITuner`도 가능하면 문자열 대신 채널 타입을 명확히 하는 편이 좋습니다.

```cpp
class ITuner {
public:
    virtual ~ITuner() = default;
    virtual int seekNextChannel() = 0;
    virtual void setChannel(int channel) = 0;
    virtual int currentChannel() const = 0;
};
```

컨트롤러는 이렇게 얇아질 수 있습니다.

```cpp
class TVChannelController {
    ITuner& tuner_;
    ChannelInputBuffer input_;
    FavoriteChannels favorites_;

    static void validateChannel(int channel) {
        if (channel < 0 || channel > 99) {
            throw std::invalid_argument("channel out of range");
        }
    }

public:
    explicit TVChannelController(ITuner& tuner) : tuner_(tuner) {}

    void pressNumber(int digit) {
        input_.pressDigit(digit);

        if (input_.consume() > 9) {
            int channel = input_.consume();
            validateChannel(channel);
            tuner_.setChannel(channel);
        }
    }

    void pressConfirm() {
        if (!input_.hasValue()) {
            return;
        }

        int channel = input_.consume();
        validateChannel(channel);
        tuner_.setChannel(channel);
    }

    void pressFavorite() {
        favorites_.toggle(tuner_.currentChannel());
    }

    void pressNextFavorite() {
        if (!favorites_.empty()) {
            tuner_.setChannel(favorites_.nextAfter(tuner_.currentChannel()));
        }
    }

    void pressOther() {
        input_.clear();
    }
};
```

주의: 위 `pressNumber()`는 방향 예시라서 실제 구현 시 `consume()`을 두 번 호출하지 않도록 `peek()` 또는 “두 자리 완성 여부” API를 추가하는 게 맞습니다. 현재 코드 기준 가장 먼저 할 개선은 `ChannelInputBuffer`, `FavoriteChannels`, `ITuner` 계약 정리입니다.
