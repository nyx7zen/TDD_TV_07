## Before / After 예시

### 1. Unit Test 개선

Before:

```cpp
TEST(TVChannelControllerTest, Stub) {
    FakeTuner tuner({1, 4, 12, 56});
    TVChannelController ctrl(tuner);
    EXPECT_EQ("0", tuner.getCurrentCH());
}
```

After:

```cpp
TEST(TVChannelControllerTest, ConfirmAppliesEnteredChannel) {
    FakeTuner tuner({1, 4, 12, 56});
    TVChannelController ctrl(tuner);

    ctrl.pressNumber(1);
    ctrl.pressNumber(2);
    ctrl.pressConfirm();

    EXPECT_EQ("12", tuner.getCurrentCH());
}

TEST(TVChannelControllerTest, OtherSeeksNextAvailableChannel) {
    FakeTuner tuner({1, 4, 12, 56});
    TVChannelController ctrl(tuner);

    ctrl.pressOther();

    EXPECT_EQ("1", tuner.getCurrentCH());
}
```

### 2. 구현 방향 예시

Before:

```cpp
void TVChannelController::applyChannel(int ch) {
}
```

After:

```cpp
void TVChannelController::applyChannel(int ch) {
    if (!isValidChannel(ch)) {
        return;
    }

    tuner_.setCH(std::to_string(ch));
}
```

### 3. 입력 버퍼 처리 예시

Before:

```cpp
void TVChannelController::pressNumber(int digit) {
}

void TVChannelController::pressConfirm() {
}
```

After:

```cpp
void TVChannelController::pressNumber(int digit) {
    if (digit < 0 || digit > 9) {
        return;
    }

    inputBuffer_ = (inputBuffer_ < 0)
        ? digit
        : ((inputBuffer_ * 10 + digit) % 100);
}

void TVChannelController::pressConfirm() {
    if (inputBuffer_ < 0) {
        return;
    }

    applyChannel(inputBuffer_);
    inputBuffer_ = -1;
}
```

## 종합 의견

TDD 관점에서는 현재 테스트가 “컨트롤러 요구사항”을 고정하지 못하고 있습니다. 먼저 버튼별 기대 동작을 실패하는 테스트로 명확히 작성한 뒤, `applyChannel()` 중심으로 작은 구현을 채우는 순서가 좋습니다.

SOLID와 테스트가능성의 출발점은 나쁘지 않습니다. `ITuner` 주입 구조는 좋지만, 아직 테스트가 그 장점을 사용하지 못하고 있어 커버리지와 회귀 방지 효과가 거의 없습니다.
